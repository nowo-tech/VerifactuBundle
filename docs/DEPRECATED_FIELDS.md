# Deprecated APIs

This document lists public APIs that are deprecated and scheduled for removal in a future major version.

## Current status (1.0.0)

There are **no deprecated public APIs** in the 1.0.0 release. The initial surface area is considered stable.

When a method, class, or configuration key is deprecated:

1. It will be marked with PHP `#[Deprecated]` (or Symfony deprecation notices) where applicable.
2. An entry will be added here and in [CHANGELOG.md](CHANGELOG.md).
3. Removal will only happen in a major version (e.g. 2.0.0), with migration notes in [UPGRADING.md](UPGRADING.md).

## Planned future notes

Reserved for upcoming deprecations. Check [FUTURE.md](FUTURE.md) for product roadmap items that are not yet deprecated APIs.
